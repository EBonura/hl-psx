# Sound contract: what hl-psx plays at each point where the original game makes a
# sound. The original side is generated from the SDK sources and the retail
# models (host/hl-catalogue); this file is the port side, one row per
# (entity class, state). `hl-catalogue check` verifies every evidence string
# against the source tree and every sample name against the cooker's tables;
# `hl-catalogue gen` writes docs/CATALOGUE-monsters.md.
#
# class|state|port|evidence|note
#
# port: comma list of  core:ID (resident core id, audio.rs SOUNDS),
#   sp:NAME (set-piece slot, hl_format::setpiece_audio), voice:GROUP (streamed
#   sentence group), none (the port is silent there), limit:TEXT (kept out for
#   a reason with numbers), na:TEXT (the original path cannot run with retail
#   data, or the sound is not the entity's).
# state `*` covers every state of the class not named by another row.
# evidence: game:"literal" / cook:"literal" joined by ;  ('-' for none).
